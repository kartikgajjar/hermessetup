# Learning register

A register, not a log: one line per lesson, moved between tables. Triage at each ship.

Cause classes: brief-gap, bar-gap (the bar passed and the defect still shipped), data-fact-missing,
scope-too-wide, cross-cutting-design, test-harness, tooling, environment, lead-process, agent-definition.
